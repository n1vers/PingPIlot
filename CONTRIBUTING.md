# Участие в разработке

## Локальная проверка

Перед pull request выполните:

```powershell
dotnet restore .\PingPIlot.slnx
dotnet build .\PingPIlot\PingPIlot.csproj -c Release
```

## Правила изменений

- сохраняйте совместимость с Windows и .NET 10;
- не добавляйте секреты, локальные данные и содержимое `bin/obj`;
- для изменений UI проверяйте работу мыши, выделения и обновления во время активных ping;
- для изменений мониторинга проверяйте тайм-ауты, отсутствие ответа и смену сетевого интерфейса;
- описывайте пользовательский эффект и способ проверки в pull request.

## Pull request

Укажите:

1. что изменено;
2. почему это нужно;
3. как проверялось;
4. есть ли изменения формата сохранённых данных.
