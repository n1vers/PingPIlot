# Безопасность

Не отправляйте в issues и pull request:

- реальные списки внутренних компьютеров;
- IP-адреса, DNS-имена и журналы мониторинга;
- файлы профиля пользователя и секреты;
- дампы, содержащие сетевую информацию.

Для сообщения о потенциальной уязвимости используйте private security advisory GitHub или свяжитесь с владельцем репозитория напрямую. Публичное описание проблемы желательно публиковать только после согласования исправления.
